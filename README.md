# 🌴 TripFlow Frontend Assignment

A modern and responsive **Destination Card** built using **Next.js**, **React**, and **Tailwind CSS** as part of the TripFlow Frontend Developer Internship assignment.

## 🚀 Live Demo

https://tripflow-assignment-five.vercel.app

## 📂 GitHub Repository

https://github.com/Varshith-cloud/tripflow-assignment

## ✨ Features

- Responsive destination card
- Premium UI design
- Smooth hover animations
- Travel destination image
- Destination name and price
- Location information
- Duration (5 Days • 4 Nights)
- Rating and reviews
- Gradient "Book Your Trip" button

## 🛠️ Technologies Used

- Next.js
- React
- Tailwind CSS
- Lucide React Icons
